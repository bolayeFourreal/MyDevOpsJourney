# Week 06: Networking And Security
## Curriculum Tracker - Stage 4: Networking & Security

### 🎯 Key Learning Objectives
- Understand IP addressing, subnets, the OSI/TCP-IP model, and basic routing.
- Explore core protocols: DNS, DNSSEC, HTTP/HTTPS, and SSL/TLS handshakes.
- Learn how to diagnose network issues using ping, traceroute, dig, nslookup, and curl.
